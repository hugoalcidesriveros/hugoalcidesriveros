## 🚀 Proyectos destacados

### ♟️ AndesChess — Plataforma de entrenamiento de ajedrez

Aplicación web progresiva (PWA) diseñada para el entrenamiento y estudio del ajedrez.

**Características:**
- Entrenamiento táctico mediante ejercicios.
- Gestión de repertorios de aperturas.
- Importación y exportación de archivos PGN.
- Integración de Stockfish para análisis.
- Autenticación mediante Firebase.

**Tecnologías:** JavaScript, Vite, Firebase, Chess.js, Chessground y Stockfish.

🌐 [Visitar AndesChess](https://andeschess.web.app)

---

### 🏆 LigaFMA — Gestión de competiciones de ajedrez

Sistema web orientado a la administración de competiciones, clubes, jugadores y encuentros.

**Características:**
- Gestión de competiciones y equipos.
- Administración de jugadores.
- Registro de encuentros y resultados.
- Autenticación y roles administrativos.
- Reglas de acceso mediante Firebase Firestore.

**Tecnologías:** TypeScript, React, Vite y Firebase.

🌐 [Visitar LigaFMA](https://ligafma.web.app/)

---

### 🔥 Firewatch Mendoza — IoT y monitoreo ambiental

Proyecto en desarrollo orientado a explorar soluciones de monitoreo ambiental mediante sensores y comunicaciones inalámbricas.

**Áreas de desarrollo:**
- Sensores y microcontroladores.
- Comunicaciones LoRa.
- Sistemas de bajo consumo.
- Redes de dispositivos IoT.
- Detección temprana de posibles focos de incendio.

**Área:** IoT, electrónica y comunicaciones.
